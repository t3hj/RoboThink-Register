# RoboThink Register: instructor guides

Plain-English guides for the teaching team. They cover everyday tasks only and
contain no curriculum content or real student information.

| Guide | Read it when |
| --- | --- |
| [1. Getting started](01-getting-started.md) | It is your first day, or you cannot sign in |
| [2. Adding and editing students](02-adding-students.md) | A new family joins, or a student's day or time changes |
| [3. Taking the register](03-taking-the-register.md) | You are running a session |
| [4. Every-other-week students and make-up sessions](04-fortnightly-and-make-ups.md) | A student attends fortnightly, or missed a session |
| [5. Lessons, assessments and feedback](05-lessons-assessments-feedback.md) | A student did not finish, or it is an assessment |
| [6. Fixing mistakes and FAQ](06-fixing-mistakes-and-faq.md) | Something looks wrong |
| [7. Student requests](07-student-requests.md) | An instructor needs a student added, or a request needs reviewing |
| [Quick reference card](quick-reference.md) | You want a one-page reminder |
| [Admin guide](admin-guide.md) | You manage staff, centres or the database |

The same short how-tos are also inside the app under **Help & guides**.
